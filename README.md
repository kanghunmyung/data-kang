# 데이터 시각화 놀이터

CSV나 엑셀 파일을 올리면 여러 방식으로 데이터를 시각화해주는 Streamlit 앱입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 지원 기능

- 막대그래프
- 원그래프
- 트리맵
- 깔때기 그래프
- 선그래프
- 영역그래프
- 버블 산점도
- 히스토그램
- 박스플롯
- 바이올린 플롯
- 밀도 그래프
- 산점도
- 밀도 윤곽 그래프
- 상관관계 히트맵
- 워드클라우드
- 누적분포 그래프
- 선버스트
- 스트립 플롯
- 요약 통계표
- 퀴즈
